# 현서의 첫 생일 초대장

2026년 11월 28일 토요일 오후 1시 30분 · 오월식당 1층.
별도의 설치나 빌드 없이 GitHub Pages에서 호스팅하는 모바일 초대장입니다.

## 사진 넣기

`images/main.jpg`에 대표 사진, `images/01.jpg` ~ `images/12.jpg`에 월별 사진을 넣어 주세요. 없는 사진은 파스텔색 자리로 표시합니다. JPG 파일을 사용하고 각 사진은 1MB 이하를 권장합니다.

생년월일은 이미지의 날짜와 생후 일수를 바탕으로 2025-11-28로 설정했습니다. 다르면 `app.js`의 `birthDate`를 수정하세요. 생후 일수와 디데이는 한국 날짜에 맞춰 자동 계산됩니다.

## GitHub Pages

저장소 Settings → Pages → Build and deployment에서 Deploy from a branch를 선택하고 `main` / `/ (root)`를 저장합니다.
사이트 주소: https://mungmoong3.github.io/mypages/

일정의 종료 시간은 표시하지 않습니다. 아이폰용 ICS에도 종료 시각이 없습니다. 구글 캘린더는 같은 시작·종료 시각으로 전달하며, 저장 화면에서 제공자가 기본 종료 시간을 제안할 수 있습니다.
